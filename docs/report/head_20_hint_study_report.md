**HEAD 任务数：** 20

**覆盖：** 全 20 任务 L0/L2/L4（Mistral）、L0/L2（120B）已齐。

## 1. 剂量-反应总览（新 20 HEAD，react baseline）

| Hint Level | 描述 | Mistral Pass | 120B Pass | 备注 |
|:----------:|:----:|:------------:|:---------:|:----|
| L0 | 无 hint | 1/20 (5%) | 14/20 (70%) | 全 20 |
| L2 | 函数名 | 5/20 (25%) | 20/20 (100%) | 全 20 |
| L4 | 行号 | 8/20 (40%) | — | 全 20 |

## 2. 因果验证结论

**Q1（定位信息是否恢复能力）：**
- Mistral：L0 → L2 通过率 5% → 25%（+20pp）；L4 为 40%。
- 120B：L0 → L2 通过率 70% → 100%。
- **结论：** 函数级/行级 hint 可部分恢复 Mistral 在 HEAD 上的表现，说明定位信息有效；剩余失败主要为**修复生成**不足。

**Q2（修复生成是否为主瓶颈）：**
- 全量 20 上，Mistral 的总体剂量曲线为 L0→L2→L4 = 1/20 → 5/20 → 8/20。
- 但收益高度集中在 QuixBugs：QuixBugs 1/9 → 4/9 → 7/9；DebugBench 0/7 → 1/7 → 1/7；Mini-nightmare 0/4 → 0/4 → 0/4。
- **结论：** 行级定位对单行算法型 HEAD 可显著缩短“最后一跳”，但对结构性更强的 DebugBench / Mini-nightmare 几乎无效；因此**修复生成**仍是更一般的主瓶颈。
- 与原 23-task 子集上观察到的 `L4 < L2` 不同，全量 20 呈现 `L4 > L2`，说明 hint 效果对任务组成高度敏感，体现干预非线性。

**Q3（120B 与 hint）：**
- 120B 在 L0 上已 70%，L2 达 100%；hint 主要提通过率或降成本。
